# Workmanship defect-code summary

Private dashboard of factory workmanship defects, counted as **failed units** (not one per spreadsheet row). Filter by manufacturing site and business unit.

## Open the dashboard

Use the GitHub Pages link for this repository (see the repo description / About section). That opens the dashboard in a browser with no Cursor install.

You can also download `index.html` (same as `defect-code-summary-2026-10-15.html`) and open it locally in Chrome, Edge, or Safari.

Do not rely on Slack, Teams, GitHub file preview, or SharePoint previews — they often show a blank page.

## Source

Charts are built from `retrofit_failure_analysis_WORKING DOCUMENT.xlsx` (Workmanship Results sheet, Failure Code, Business Unit, Manufacturer Site, Number of Failed Units).
