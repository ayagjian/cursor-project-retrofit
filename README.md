# Workmanship defect-code summary

Private dashboard of factory workmanship defects, counted as **failed units** (not one per spreadsheet row). Filter by manufacturing site and business unit.

## Open the dashboard

Download or clone this folder, then open this file in Chrome, Edge, or Safari:

`defect-code-summary-2026-10-15.html`

Do not rely on Slack, Teams, or SharePoint previews — they often show a blank page. Open the file in a browser instead.

## Source

Charts are built from `retrofit_failure_analysis_WORKING DOCUMENT.xlsx` (Workmanship Results sheet, Failure Code, Business Unit, Manufacturer Site, Number of Failed Units).
